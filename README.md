# 비즈온(Vids On) 웹 버전

https://vidson.moaonlabs.com

모아온랩스가 만드는 무료 영상 편집기 '비즈온'의 웹 실행 파일입니다. 브라우저(Chrome·Edge 최신 버전)에서 설치 없이 사진·영상·글자·음악으로 영상을 만들고 MP4로 저장합니다. 사진·영상은 사용자 PC 밖으로 전송되지 않습니다.

- 이 저장소에는 배포용 실행 파일만 있습니다. 개발 소스는 별도 비공개 저장소에서 관리합니다.
- 함께 쓰는 공개 소프트웨어: three.js(MIT), mp4-muxer(MIT), 나눔고딕·나눔명조·나눔손글씨(SIL OFL 1.1). 자동 자막·손 추적은 사용자 동의 후 Transformers.js·Whisper·MediaPipe(Apache-2.0/MIT)를 내려받아 브라우저 안에서만 실행합니다.
